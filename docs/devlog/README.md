# Diário de desenvolvimento (devlog)

Um arquivo por dia de trabalho: `AAAA-MM-DD.md`. Escrito pelo `documentador` ao fim de cada tarefa ou sessão.

Serve para responder, meses depois, "o que eu estava fazendo e por quê?". O **o quê** detalhado já está no git; aqui fica o **porquê**, as decisões pequenas e o que ficou pendente.

## Formato de cada entrada
```markdown
## <Tarefa>
- **O que foi feito:** ...
- **Por quê:** ...
- **Decisões:** ... (decisão de arquitetura vira ADR)
- **Pendências:** ...
```
